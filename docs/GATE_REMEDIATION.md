## Presentation-safe path

Use the current foundation demo as documented in [README.md](../README.md#run-the-local-foundation-demo): API readiness, local authorized GeoJSON preview, and request-structure validation only. State clearly that it does not retrieve imagery or produce crop, phenology, moisture-stress, or irrigation estimates. This branch adds a catalog-discovery fallback and gate documentation; it does not change the demo UI or its API behavior.

## Reopen criteria for scientific model implementation

Start model-fitting work only after the selected AOI, source terms, verified label semantics, complete `CON-03`, feature/grid/time conventions, supported crop class map, and spatially isolated evaluation plan are documented. Software tests may use labelled synthetic arrays, but their predictions and metrics must never be presented as scientific evidence.
